# AMR-prediction-and-finding-resistance-genes
Collection of MIC data from BV BRC of Klebsiella pneumoniae for 3 drugs - Ciprofloacin, Meropenem, Colistin.
Counting 11-mers of the genomes of different strains of Klebsiella pneumoniae to make a sparse matrix.
Feature engineering the matrix.
Applying different ML algorithms to see which gives the best Essential Agreement.
Analysing the shortcomings of the models to find which genes it failed to predict correctly.
